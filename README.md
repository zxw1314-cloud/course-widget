# 桌面课表备忘录（course-widget）

Electron 开发的 Windows 桌面小工具：**每周课表 + 上课/待办/活动提醒 + 半透明桌面挂件**。本地存储、无需账号、无广告、无捆绑。

代码位于 [`course-widget/`](course-widget/) 子目录，功能与使用方法见 [course-widget/README.md](course-widget/README.md)。

> 说明：本仓库根目录同时是本地项目目录 `桌面备忘录`，仅提交 course-widget 相关文件；课表等个人数据保存在 `%APPDATA%\course-widget\data.json`，不会进入仓库。
