# 桌面课表备忘录（course-widget）

一个 Electron 开发的 Windows 桌面小工具：**每周课表 + 上课/待办/活动提醒 + 半透明桌面挂件**。本地存储、无需账号、无广告、无捆绑、开源（MIT）。

> 代码在 [`course-widget/`](course-widget/) 子目录；本仓库根目录同时是本地项目目录，只提交 course-widget 相关文件。

## ✨ 功能

- 📅 **14 天双周挂件**：上行=本周 7 天（课程+待办+活动），下行=下周 7 天；今天高亮
- 🧩 **合并连堂课**：连续的同名课合成大框，左侧起止时间竖排、右侧课程名+节数徽标+地点（可开关）
- ✏️ **课程简写**：全名→简写映射（如"数据结构与算法"→"数算"），挂件只显示简写，悬停看全称
- 🎨 **三色事项**：课程=白字（可自定义颜色/教师）、待办=黄字（带截止时间）、临时活动=红字（**带地点**）；待办与活动**过期自动标红提示**，可一键清除过期项
- 🔔 **多次提醒**：课程/待办/活动支持多个提醒点 + 周期重复提醒，到点弹系统通知
- 🔊 **提醒声音**：课程/待办/活动/考试弹系统通知时同时播放提示音（纯 WebAudio，无音频文件），防止错过通知
- 🎯 **倒数日 / 考试**：支持开始时间+地点，当天到点提醒（如"考试提醒 期末高数 @ 金明综合楼101 (14:00)"）
- 🪟 **桌面挂件形态**：半透明（20%~100% 可调）、自由摆放 + 手动缩放、除交互控件外**鼠标穿透**不挡桌面图标
- 🤖 **JSON 导入课表**：内置可复制的 AI 提取提示词，把课表截图一键转成课表数据
- ⚡ **即时刷新**：保存后挂件立即更新；未保存修改会提醒
- 🧩 **托盘常驻** + 开机自启 + 导出/导入备份

## 🚀 快速开始

**环境**：Windows 10/11，Node.js 18+（开发运行需要）。

```powershell
cd course-widget
npm install
npm start
```

首次会打开**设置窗口**：录入课表后点「**保存并应用到桌面**」，挂件出现在桌面右下角。之后启动直接恢复挂件，设置窗口通过托盘或挂件 ⚙ 找回。

> 也可以双击项目里的 `启动桌面课表.bat`。

## 📖 使用教程

### 1. 录入作息表与课表
设置 → 课表 tab：
- **节次时间表**：第 1~N 节的起止时间（支持"中午1节"这类非编号节次）
- **课表网格**：点击格子添加/编辑课程，支持课程名、教师、地点、颜色、周次（如 `1-16`）、提醒
- 跨节次课程（如 3-5 节连上）：在同一个格子上分别填，或直接用 **JSON 导入**（见第 7 步）

### 2. 应用到桌面
点「保存并应用到桌面」，半透明双周挂件出现在右下角。之后：
- **左上角 ⠿ 手柄**：按住拖动位置
- **四边四角**：拖动缩放（位置/大小自动记忆）
- **日期格右上角 +**：打开"当日窗口"，查看/添加待办和临时活动
- **其余区域全部鼠标穿透**：不挡桌面图标的点击

### 3. 配课程简写
设置 → 课表 tab →「课程简写」：给每门课填 2~4 字简写（如"数据结构与算法"→"数算"），挂件里只显示简写，悬停可看全称；留空则显示全称。

### 4. 合并连堂课
设置 → 设置 tab →「合并连堂课程」（默认开启）：连续的同名课合成一个大框显示起止时间（如 `10:00 ↓ 12:30 大物 ×3`）。

### 5. 考试与倒数日
设置 → 倒数日 tab：名称 + 日期 +（可选）开始时间 + 地点。挂件显示「还有 N 天 · 🕒时间 · 📍地点」，当天且有时间的考试到点前会弹提醒。

### 6. 提醒与提醒声音
- 课程/待办/活动都支持：**提前 N 分钟提醒**（可多个，如 `10,60`）+ **周期重复提醒**（截止前 X 分钟起每 Y 分钟提醒一次）
- 设置 → 提醒声音：勾选"弹通知时播放提示音"，每次弹系统通知会同时响一声提示音（可试听、调音量），防止没看到通知

### 7. 用 AI 从截图导入课表
1. 设置 → 课表 tab →「复制 AI 提取提示词」
2. 把课表截图 + 提示词交给任意多模态 AI（GPT / 通义千问 / Claude 等）
3. AI 返回 JSON →「打开导入面板」粘贴 → 解析预览 → 确认导入 → 保存并应用到桌面

JSON 结构示例：
```jsonc
{
  "semesterStart": "2026-09-07",
  "periods": [ { "index": 1, "label": "第1节", "start": "08:00", "end": "08:45" } ],
  "courses": [
    { "name": "数据结构与算法", "abbr": "数算", "day": 3, "periods": "11-12",
      "location": "金明综合楼2", "teacher": null, "weeks": null, "color": "#77b5e8" }
  ],
  "abbr": { "数据结构与算法": "数算" }
}
```
- `day`：1~7 或"周一"~"周日"；`periods`：数字 / 数组 / `"3-5"` 范围；`weeks`：数组或 `"1-16"` 或 null（每周）
- 也支持「导出当前课表 JSON」后让 AI 修改再导回

### 8. 数据与备份
- 数据保存在 `%APPDATA%\course-widget\data.json`（明文 JSON，**不会进入本仓库**）
- 设置 → 导出备份 / 导入备份；或直接复制 data.json
- 无账号、无云同步，纯本地

## 📦 打包成 exe（非开发者也能用）

```powershell
cd course-widget
npm run dist            # 便携版：course-widget/release/course-widget-<版本>-portable.exe（双击即用，免安装）
npm run dist:installer  # 安装版：course-widget/release/course-widget-<版本>-setup.exe（可自选安装目录/建桌面快捷方式）
```

- 便携版 exe **双击直接运行**，无需装 Node.js/npm，绿色免安装，数据仍存 `%APPDATA%\course-widget\data.json`
- 首次打包会联网下载 electron-builder 组件；网络受限时见 course-widget/README 的打包说明

```powershell
cd course-widget
```
