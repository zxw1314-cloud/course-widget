# 桌面课表备忘录 · 领域词汇

本上下文描述"桌面课表备忘录"这款 Windows 桌面小工具的领域语言：围绕课表、待办、临时活动、提醒与桌面挂件的核心概念。

## Language

**课表（Timetable）**:
每周固定重复的课程安排，按"周几 × 第几节"组织。
_Avoid_: schedule, 课程表

**节次（Period）**:
一天中的第 N 节课，含固定起止时间（如第 1 节 08:00~08:45）。
_Avoid_: slot, 课时

**周次（Week）**:
学期中的第几周，用于过滤课表（如"1-16 周"或"1,3,5 周"）。由"学期起始日（第 1 周周一）"推算当前周。
_Avoid_: 星期

**课程（Course）**:
课表中的一条固定安排：名称、节次、星期、可选地点、可选周次、可选提醒。挂件中只显示开始时间与**简写**（若配置），地点换到小字一行；连续节次的同名课默认**合并**为一个大框显示起止时间（设置 mergeConsecutive 可关）。
_Avoid_: class, 科目

**连堂课（Consecutive Course）**:
同一课程在相邻节次连续出现（如第 3/4/5 节都是大学物理实验）。挂件合并显示为一个大框，时间显示"起止"（10:00~12:30）；判据=同名+同老师+同颜色，地点可不同（并列显示）。
_Avoid_: 合并课程, merged

**课程简写（Abbreviation）**:
设置页为课程全名配置的 2~4 字短名（如"数据结构与算法"→"数算"），挂件显示用；保存在 settings.courseAbbr（全名→简写）。
_Avoid_: 简称, 缩写

**待办（Todo）**:
日期下的一条清单项：文字 + 可选截止时间 + 完成状态。挂件中以黄色显示。
_Avoid_: task, 备忘录条目

**临时活动（Event）**:
日期下的一次性事项：标题 + 可选时间。不勾选完成，挂件中以红色显示。
_Avoid_: activity, 日程

**截止时间（Deadline）**:
待办的可选完成时限（HH:MM）。有截止时间才有提醒。
_Avoid_: due

**提醒点（Reminder Point）**:
"提前 N 分钟提醒一次"的配置，可配多个（如提前 10、60 分钟）。
_Avoid_: 闹钟

**周期重复提醒（Repeat Reminder）**:
从"截止前 X 分钟"起，每隔 Y 分钟提醒一次，直到截止。
_Avoid_: 循环提醒

**教师（Teacher）**:
课程的可选授课教师，设置课程时填写，课表网格、挂件与当日窗口中显示。
_Avoid_: professor

**课程颜色（Course Color）**:
课程的可选标记色，用于在课表网格、挂件与当日窗口中区分不同课程。
_Avoid_: 课程主题

**上下课铃声（Class Bell）**:
到上课/下课时间播放的合成提示音（纯 WebAudio，无音频文件）。仅在有课程的节次触发，可试听与调音量。
_Avoid_: 闹钟

**倒数日（Countdown）**:
一个目标日期（考试、假期等）+ 标题 + 可选颜色 + 可选开始时间/地点；挂件显示最近 3 个「还有 N 天 · 🕒时间 · 📍地点」。
_Avoid_: 倒计时

**考试（Exam）**:
填了时间与地点的倒数日，用于考场安排；当天到点前按「默认提前提醒」弹系统通知，通知标题含时间与地点。
_Avoid_: 测验, 测验日

**挂件（Widget）**:
自由摆放（左上角手柄拖动）的 14 天双周视图窗口：半透明（不透明度 20%~100% 可调，即时生效）、四边四角手动缩放、位置与大小持久化；每个日期格右上角有 "+" 按钮；课程项=开始时间+简写（地点小字换行）。
_Avoid_: 小组件, desktop widget

**未保存提醒（Unsaved-Changes Reminder）**:
设置窗口在有未保存修改时于标题栏显示"● 未保存"，关闭窗口时弹出确认框（保存并应用到桌面/仅保存/不保存），防止误关丢失课表/设置。
_Avoid_: 脏标记, dirty flag

**当日窗口（Day Window）**:
点击挂件上某个日期弹出的窗口，用于查看该日课程/待办/活动并编辑。
_Avoid_: popup, 详情窗

**穿透模式（Click-Through）**:
挂件空白区域的鼠标事件穿透到桌面（不挡图标/桌面操作）。主进程每 50ms 轮询光标位置，仅当光标命中 14 个加号、移动/缩放手柄、右上角按钮时才取消穿透；挂件窗口 focusable=false（不抢焦点，首次点击不被系统吞掉）；数据保存后主进程广播 data:changed 即时刷新挂件。
_Avoid_: 透明点击
