# 手机远程桥：局域网/樱花frp + 只读今日 + 新增待办（带 token 与离线队列）

- 状态：已实施（2026-08-02）
- 相关：ADR-0004（本地 JSON 存储）、ADR-0006（挂件交互）

## Context
用户希望用手机（网页/PWA + Android APK）向电脑的课表备忘录"投递"待办：在外出时把临时的待办加到电脑上，让挂件即时更新。电脑在宿舍局域网内，外网访问需内网穿透（用户选定**樱花frp**）。安全、范围、离线行为等经 grill 逐项确认。

## Decision
1. **电脑端 HTTP 服务**：Electron 主进程内置 Node `http` 服务，固定端口 **8723**、绑定 `0.0.0.0`（局域网与 frp 均可达）。设置页有总开关 + 模式（仅网页 / 仅App / 都开），关闭即停服、完全不可达。
2. **认证**：固定随机 token（设置页生成/显示/复制/重生成），所有 `/api/*` 请求校验 `Authorization: Bearer <token>`（`/api/health` 例外）。HTTP 明文 + token 对低敏感待办数据够用；HTTPS 列为后续。
3. **API 范围（手机只读 + 只增）**：
   - `GET /` → 手机网页（模式含 web/both 时）
   - `GET /api/health` → 存活检查（免 token）
   - `GET /api/today` → 今日课表/待办/活动/倒数（只读）
   - `POST /api/todo` → 新增待办（text 必填，date 默认今天，deadline/points 可选；提醒默认提前 10 分钟）
   - **手机无删除/修改权限**。
4. **离线队列**：手机端（网页 localStorage / App 内）把"发送失败"的待办存进待发送队列，连接恢复后自动补发；电脑仍是唯一真源，手机只是异步投递员。
5. **APK 形态**：Android WebView 套壳加载同一套手机网页，token 由页面内 localStorage 管理；不做系统通知/闹钟（用户判定过重，列为愿望清单）。
6. **电脑在线预期**：不做保活/唤醒；应用在跑即可连，文档说明"电脑需开机且应用运行"。

## Consequences
- 手机加待办后，电脑侧沿用 `saveData()` + `broadcastDataChanged()`，挂件即时刷新，无需改动现有数据模型。
- 设置页新增"手机连接"卡片：开关、模式、令牌、本地地址；樱花frp 映射 8723 端口即外出可用。
- 安全性：公网暴露面=仅 8723 端口 + token 校验；未启用时服务不监听。
- 局限性：明文 HTTP（frp 中继可被审计流量）；无推送通知；APK 为 WebView 壳（非原生体验）。
