# ADR-0005: 上下课铃声与倒数日（参考 study-desk）

> 日期：2026-08-02 · 状态：已采纳

## 背景

course-widget 已有「提前 N 分钟提醒 + 周期重复提醒」，但缺少到点的**声音**反馈；
同时用户希望像 study-desk 一样在挂件上看到**倒数日**（考试、假期等）。

## 决策

### 1. 铃声：主进程调度 + 渲染进程纯 WebAudio 合成

- 主进程每 10 秒检查当前 HH:mm 与节次起止时间（复用 `data.periods`）；
  命中且当天该节次**有课程**（含周次过滤）时，向挂件窗口广播 `bell:ring`（`on`/`off`）。
- 挂件窗口用 `renderer/chime.js`（参考 study-desk `lib/audio.ts`，MIT）纯 WebAudio 合成铃声：
  校园电铃 / 音乐钟声 / 叮咚 / 清亮铃声 / 木琴 / 和弦，零音频文件、离线可用。
- 铃声仅在有课的节次触发（个人课表语义）；原有系统通知提醒保持不变，不重复弹窗。
- 配置项：`bellEnabled`、`bellPreset`、`bellVolume`（设置窗口可试听）。

### 2. 倒数日：轻量数据 + 挂件展示

- 新增 `countdowns[]`：`{ id, title, date, color }`，设置窗口管理（增/删）。
- 挂件在 `showCountdown` 开启时显示最近 3 个未过期倒数日。

### 3. 课程信息增强

- 课程新增 `teacher`、`color`（可选），课表网格 / 挂件 / 当日窗口按颜色区分并显示教师。

## 后果

- 优点：无新增依赖、无音频资源、迁移向后兼容（旧数据自动补 `teacher/color/countdowns`）。
- 代价：铃声依赖挂件窗口存活；窗口隐藏时仍会播放（Chromium 后台音频可能被节流，可接受）。
- 挂件头部新增「当前课/下节课」状态行，实时反映今天课程进度。
